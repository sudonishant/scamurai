# Security Policy

See [docs/SECURITY.md](docs/SECURITY.md) for the full threat model, SSRF
boundaries, authentication design and deployment hardening checklist.

## Reporting a vulnerability

Please do **not** open a public issue. Use
[GitHub Private Vulnerability Reporting](https://github.com/sudonishant/scamurai/security/advisories/new) or contact the project maintainers.

Given that this tool ingests untrusted third-party content and stores
investigative evidence, please include: the affected endpoint or module,
whether case isolation is bypassed, and a minimal reproduction.
